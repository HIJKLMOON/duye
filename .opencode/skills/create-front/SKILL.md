## What I do
- 根据定义的风格设计一个前端网站
- 按照需求设计网站布局

## Execution

### 1. 准备
- [ ] 网站使用技术栈：React、React-Route、Redux、Tailwind CSS、TypeScript、Ant Design、CSS Modules、Vite
- [ ] 根据输入的项目描述，分析网站的实际内容，并基于此设计网站设计的任务

### 2. 核心处理
- [ ] 网站设计风格：
  - [ ] 导航区
    - [ ] 页面导航部分位于页面左侧，导航区的顶部为网站的logo
    - [ ] 导航区的每个导航由图标和文字横向组成，每个导航竖向排列
    - [ ] 导航区最底部为个人中心导航
  - [ ] 内容区
    - [ ] 内容区的宽度必须为整个页面除导航区外的区域的宽度
    - [ ] 内容区的内容如果需要进行网络请求，需要完成对应API，并对于请求失败使用Ant做提示
    - [ ] 内容区的内容排版需整齐，默认为居中与内容区
    - [ ] 内容区的内容可以独立上下滚动，不能影响导航区
    - [ ] 内容区如果存在搜索框，需使用网络请求，请求热点信息和用户个人最近搜索，用户最近搜索可存于localstorage
- [ ] 使用路由守卫，完成登录鉴权、动态路由、按钮级权限控制，当页面的请求需要登录时，页面弹出弹窗指引用户是否登录
- [ ] 基于 Element Plus 封装通用组件（表格、表单、弹窗）
- [ ] 封装 Axios 请求库，统一处理请求拦截、响应报错、Loading 加载、跨域等问题；
- [ ] 使用 ECharts 实现数据可视化图表（折线图、饼图），完成后台数据展示与筛选功能；
- [ ] 适配多分辨率屏幕，使用 Tailwind CSS 实现响应式布局，优化页面渲染速度

### 3. 验证与输出
- [ ] 将最终的项目打包运行

## Rules

### Must do
- 必须使用规定的技术栈
- 必须分许出详细的网站设计任务，并依次完成
